A program that writes one original sentence about the best advice ever received (118 characters) to `/output/entry.txt` for make.fun's "The Best Advice I Ever Got" bounty. The sentence is the whole entry: one piece of advice, standing alone — *"My father said never trust a man who is rude to waiters, and twenty years later I have never once seen that rule fail."* It scores six candidate sentences against the judge's own criteria — staying on subject, advice worth carrying, a real voice recalling a real moment, tightness, a landing that stays — and writes the winner. It runs offline, reads nothing from the network, and writes the same text on every run.

## Run it

```sh
python3 main.py
```
